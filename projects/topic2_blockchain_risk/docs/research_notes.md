# Topic 2 Research Notes: Blockchain Risk

## Research question

This topic studies blockchain-related risk signals using incident ledgers or weak-label indicators.

## Data plan

The project may use a manually constructed incident ledger. Each event should include date, event type, source, and notes.

## Method plan

The first step is to create a transparent benchmark based on noisy risk labels.

## Claim boundary

Weak-label alerts are not the same as verified fraud ground truth. The analysis should be interpreted as risk-signal exploration rather than confirmed fraud detection.
